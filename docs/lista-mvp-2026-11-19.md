## Como ler esta lista

- 🔴 **MVP-BLOQUEIA**: precisa estar resolvido antes do primeiro escritório testar.

- 🔵 **PÓS-MVP**: depois do teste, para o lançamento (05/01/2027) ou para mais adiante.

**Esforço**
- **P**: até meio dia.
- **M**: 1 a 3 dias.
- **G**: mais de 3 dias.

**Tipo**
- Correção
- Decisão (sua)

## O que é o MVP de testes (proposta)

A ideia é o escritório piloto usar o LegalOS **no lugar do Astrea no dia a dia**, com o que já está mais sólido. Tudo o que não foi validado no mundo real fica desligado durante o teste.

| Entra no MVP | Fica desligado no MVP |
|---|---|
| Login, 2FA, escritório, equipe e permissões | Módulo judicial: robôs, certificados, protocolo, Box |
| Importação do Astrea | Campanhas em massa de WhatsApp |
| Clientes, processos e partes | WhatsApp por QR-Code (Baileys) |
| Prazos (com tabela corrigida), tarefas, agenda e kanban | Conciliação bancária |
| Documentos e modelos, cofre de senhas (corrigido) | Cobrança Asaas: entra só se o piloto quiser, em sandbox |
| Financeiro básico: contas, honorários, faturas | Cálculo trabalhista (até a revisão) |
| Cálculos cíveis TJSP e de prazos | Vídeo do Cowork, agentes de IA do Cowork |
| Intimações pelo DJEN, com verificação manual | "Modo ações" da RUTE (grava sem aprovação) |
| Atendimento: WhatsApp oficial da Meta **só depois do teste real**, e e-mail | API pública e MCP para terceiros (só convidados) |
| RUTE em modo consulta | Protótipos |
| Portal do cliente | |
| Relatórios, metas e automações simples | |

## Resumo: o caminho para o MVP

**Bloqueia o MVP (🔴): 35 itens, quase todos pequenos.**

- **Semana 1, correções:** itens 7–16, 29–31, 37, 39.
- **Semana 1, desligar:** itens 43–46 e 49.
- **Semana 2, interface, produção e piloto:** itens 50, 55–59, 90, 91 e 101.
- **Semana 2, validação:** itens 65 e 66, com as decisões 1, 2, 3 e 6 tomadas antes.

**Recomendado para o MVP (🟠): 34 itens.** Podem ser feitos durante as 4 semanas do piloto. Os mais valiosos são:

- 54: reportar problema;
- 63: DJEN automático;
- 71: lembrete por e-mail;
- 72: feriados locais;
- 74 e 75: NPS e telemetria;
- 77: limite de upload.

**Depois do MVP (🔵): 32 itens.** Ficam para o lançamento de 05/01/2027 e para depois.

Ordem sugerida para começar agora: **7 → 8 → 9 → 10 → 11 → 14 → 15 → 16 → 29 → 30**. São todas correções pequenas, de até meio dia cada, e destravam o que já está quebrado.
